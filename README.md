## 🌍 What It Does

Carbon intensity of electricity varies dramatically across cloud regions:

| Region | Grid Zone | Emission Factor |
|--------|-----------|-----------------|
| AWS EU North (Stockholm) | SE (Svenska) | **13 gCO₂/kWh** ✅ |
| AWS US West (Oregon) | WECC-NW (Hydro) | 132 gCO₂/kWh |
| AWS US East (Ohio) | PJM | 380 gCO₂/kWh |
| AWS Asia Pacific (Mumbai) | IN-WE (Coal) | **708 gCO₂/kWh** ❌ |

This platform:
1. **Trains** a Random Forest model on 1M+ energy records across 51 countries and 8 sectors
2. **Predicts** carbon intensity per cloud region using ML + grid-zone emission factors (EPA eGRID 2023)
3. **Fetches** real-time data from the Electricity Maps API when available
4. **Recommends** the Top-3 lowest-carbon regions via a web interface
5. **Quantifies** absolute CO₂ savings in kg for your workload

## 🔑 Getting Your Electricity Maps API Key

The Electricity Maps API provides **real-time** carbon intensity data. Without it, the system still works using ML predictions — but live data gives more accurate results.

### How to get a free API key:

1. Go to **[https://www.electricitymap.org/api](https://www.electricitymap.org/api)**
2. Click **"Get API Key"** → Sign up for a free account
3. Copy your API key from the dashboard

### How to set it:

**Windows (PowerShell):**
```powershell
$env:ELECTRICITY_MAPS_API_KEY = "your_api_key_here"
```

**Windows (Command Prompt):**
```cmd
set ELECTRICITY_MAPS_API_KEY=your_api_key_here
```

**Mac / Linux:**
```bash
export ELECTRICITY_MAPS_API_KEY=your_api_key_here
```

> Set API key as an environment variable only.

**To make it permanent on Windows:**
1. Search "Environment Variables" in Start Menu
2. Click "Edit the system environment variables"
3. Click "Environment Variables" → "New" under User Variables
4. Name: `ELECTRICITY_MAPS_API_KEY`, Value: `your_key`

## 🖥 Using the Website

The web interface has the following controls:

| Field | Description |
|-------|-------------|
| **Latitude / Longitude** | Your location (or click Auto-Detect) |
| **Cloud Provider** | Filter by AWS, Azure, GCP, or All |
| **Workload Type** | General Purpose, ML Training, Batch, Real-time, Storage |
| **Priority** | 🌱 Minimise Carbon · ⚖️ Balanced · ⚡ Minimise Latency |

**Priority modes explained:**

- `🌱 Minimise Carbon` — Sorts purely by carbon intensity. Picks the greenest region regardless of distance.
- `⚖️ Balanced` — Sorts by `carbon_intensity + (distance_km / 500)`. Balances green vs. close.
- `⚡ Minimise Latency` — Sorts purely by distance. Picks the nearest region.

**Output cards show:**
- Carbon intensity (%) with colour-coded bar (green → yellow → red)
- Distance from your location
- Renewable energy percentage
- CO₂ saved vs. worst region (%)
- Absolute CO₂ saved in kg (for 100 kWh workload)
- Data source tag: `● LIVE DATA` / `ML PREDICTED` / `HISTORICAL`

## 📡 API Reference

All endpoints return JSON. Base URL: `http://127.0.0.1:5000`

### `POST /api/recommend`

Get Top-3 green region recommendations.

**Request body:**
```json
{
  "lat": 20.59,
  "lng": 78.96,
  "provider": "all",
  "workload": "general",
  "priority": "balanced",
  "workload_kwh": 100.0
}
```

| Field | Options | Default |
|-------|---------|---------|
| `provider` | `"all"`, `"aws"`, `"azure"`, `"gcp"` | `"all"` |
| `priority` | `"carbon"`, `"balanced"`, `"latency"` | `"balanced"` |
| `workload_kwh` | any float | `100.0` |

**Response:**
```json
{
  "top_recommendations": [
    {
      "rank": 1,
      "provider": "AWS",
      "region_name": "EU North (Stockholm)",
      "country": "Sweden",
      "carbon_intensity": 4.2,
      "distance_km": 7842,
      "renewable_pct": 91.3,
      "data_source": "ml_predicted",
      "carbon_savings_pct": 94.1,
      "co2_saved_kg": 69.5,
      "co2_kg_per_100kwh": 1.3
    }
  ],
  "all_recommendations": [...],
  "co2_summary": {
    "best_kg_per_100kwh": 1.3,
    "worst_kg_per_100kwh": 70.8,
    "max_saving_kg": 69.5
  }
}
```

## 📈 Model Performance

| Model | MAE (%) | RMSE (%) | R² Score |
|-------|---------|----------|----------|
| Linear Regression | 2.487 | 3.297 | 0.9825 |
| Decision Tree | 0.518 | 1.098 | 0.9981 |
| **Random Forest ★** | **0.216** | **0.465** | **0.9997** |
| Gradient Boosting | 0.247 | 0.463 | 0.9997 |

**Why Random Forest?**
- Lowest MAE (0.216%) — most accurate predictions
- Best cross-validation R² — generalises well to unseen countries
- Handles non-linear interactions between energy sectors
- Robust to outliers in energy mix data

**Training dataset:**
- 1,048,575 records
- 51 countries, 8 sectors (Coal, Gas, Oil, Solar, Wind, Hydro, Nuclear, Other)
- 2019–2025 (7 years)
- 80/20 train/test split, `random_state=42`

## ☁️ Deployment on AWS EC2

### Step 1 — Launch EC2 instance

1. Go to AWS Console → EC2 → Launch Instance
2. Choose: **Ubuntu 22.04 LTS**, type **t2.micro** (free tier)
3. Security Group — add these **Inbound Rules**:
   - Type: Custom TCP, Port: **5000**, Source: **0.0.0.0/0**
   - Type: SSH, Port: **22**, Source: **My IP**

### Step 2 — Connect via SSH

```bash
ssh -i your-key.pem ubuntu@YOUR_PUBLIC_IP
```

### Step 3 — Setup on EC2

```bash
sudo apt update && sudo apt install -y python3-pip git

git clone https://github.com/hpatel09112004/carbon-aware-cloud.git
cd carbon-aware-cloud

pip3 install -r requirements.txt
```

### Step 4 — Upload dataset from your local machine

Open a **new local terminal**:
```bash
scp -i your-key.pem energy_global_datas_2026-04-07.csv ubuntu@YOUR_PUBLIC_IP:~/carbon-aware-cloud/
```

### Step 5 — Train and run

Back on EC2:
```bash
python3 train_model.py

# Set API key (optional)
export ELECTRICITY_MAPS_API_KEY=your_key_here

# Run persistently (stays alive after terminal closes)
nohup python3 cloud_final.py > app.log 2>&1 &
```

### Step 6 — Access your deployment

```
http://YOUR_PUBLIC_IP:5000
```

**For production (recommended):**
```bash
pip3 install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 cloud_final:app
```

## 🔧 Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `FileNotFoundError: energy_global_datas...csv` | CSV not in project root | Move CSV to same folder as `train_model.py` |
| `FileNotFoundError: carbon_model.pkl` | Model not trained yet | Run `python train_model.py` first |
| `GET / HTTP/1.1" 404` | `index.html` not found | Place `index.html` in same folder as `cloud_final.py` |
| `Port 5000 already in use` | Another process on port 5000 | Run `flask run --port=5001` or kill the other process |
| `Module not found` | venv not activated | Run `.\venv\Scripts\Activate.ps1` (Windows) or `source venv/bin/activate` (Mac/Linux) |
| API returns same CI for all US regions | Grid-zone offsets not applied | Ensure you're using the latest `cloud_final.py` with `ci_offset` in CLOUD_REGIONS |
